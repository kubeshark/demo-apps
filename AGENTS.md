# demo-apps - invariants

This file states facts a reader needs before changing anything. It is kept short on purpose.

## Layout

```
cmd/<service>        one Go binary per service, one image per binary, built by ko (.ko.yaml)
internal/flows/<f>   one flow: markers.tsv, the gateway-side client (flow.go), the service (service.go)
internal/            shared Go code (markers, flowrun, httpx)
proto/               protobuf sources; gen/ is committed and CI checks drift (make check-generated)
clients/<lang>       non-Go TLS clients (java, python, node)
deploy/chart         the Helm chart, the only deployment definition
deploy/chart/files/markers   copies of each markers.tsv for the ConfigMap, generated by make markers,
                     drift-checked in CI
deploy/kubeshark-values.yaml   Kubeshark values that make every flow visible
hack/                budget check, smoke test
terraform/           ECR Public repositories and the CI role, applied by hand
```

There is no generated aggregate manifest. The chart is the single description of every workload.

## Services

| Service | Port | Role |
|---|---|---|
| gateway | 8080 http | UI, `GET /api/flows`, `POST /api/flows/{name}/run?variant=ok|slow|error`; first hop of every flow |
| runner | none | calls the gateway on each flow's interval; config from ConfigMap, reloaded every 5s |
| catalog | 8080 http | redis cache in front of mysql |
| inventory | 9090 grpc | stock and reservations in mongodb |

A flow is registered in the gateway when the address of its first hop is set
(`CATALOG_URL`, `INVENTORY_ADDR`); the chart sets exactly the addresses of the enabled flows.
The runner's variant schedule: every `slowEvery`-th run is slow, every `errorEvery`-th is the
error path, the rest are ok. With `gateway.externalURL` set, every second run goes there.

## Registry

Every image resolves through one name: `public.ecr.aws/l3y1d4r0/kubeshark/demo-apps/<service>`
for images built here, `public.ecr.aws/l3y1d4r0/kubeshark/mirror/<upstream>` for third-party
servers. Mirrors are copied by digest from `mirrors.yaml`; the chart pins the same digests. No
repository carries an expiry lifecycle rule. No image is tagged `latest`.

## Flows

A flow is a directory under `internal/flows/<name>` with a `markers.tsv`
(`kind<TAB>value<TAB>what`, kinds `keep` and `vanish`). The service embeds the file and puts every
value on the wire; a checker reads the same file. Enabling `flows.<name>.enabled` in the chart
renders the services and servers that flow needs.

| Flow | Path | Servers | Error path | Slow path |
|---|---|---|---|---|
| catalog | gateway -> catalog (http) -> redis -> mysql | redis (requirepass), mysql (user/password) | query against the table named by the TABLE marker, mysql 1146, http 500 | `SELECT SLEEP(2)` |
| inventory | gateway -> inventory (grpc) -> mongodb | mongodb (root user, authSource=admin) | Reserve more than available, grpc FailedPrecondition | server-side 2s delay in GetStock |

Marker values follow `KSKEEP-<FLOW>-<FIELD>-<REST>`; code selects values by FIELD
(`Markers.Field("SKU")`, `Markers.One("USER")`), never by literal. Seed data is written on service
start, idempotently, from the markers.

## Dissector constraints the drivers respect

- Redis: RESP2 only, clients must not negotiate RESP3.
- MongoDB: wire compression off.
- PostgreSQL plaintext flows use `sslmode=disable`; TLS variants rely on the tracer.
- Kafka: client API versions pinned to what the dissector decodes; the unpinned scenario is off by default.
- HTTP/2 needs the client preface or an `h2c` upgrade; WebSocket enters only via an HTTP/1.1 upgrade.
- LDAP: no StartTLS; LDAPS relies on the tracer.
